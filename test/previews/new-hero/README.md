# new hero preview

This preview combines the test page's intro and pointer-lit grid with the pixel typing and particle palettes from `test/samples/helloworld.html`. The triangle shader runs behind the hero copy.

Run from the repository root:

```powershell
pnpm dev:new-hero
```

Click the scene to replay the title animation. Use the colour swatches to change the particle palette; the triangle mode control remains in the upper-right corner.
