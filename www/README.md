# paryx.uk

The main website for Paryx. It is home to projects, development, and whatever else ends up being built.

The site shares the blog’s minimal dark theme, Sora headings, and responsive navigation, with projects, live activity, local clocks, and contact information.

Visit [`paryx.uk`](https://paryx.uk)

The Games section uses a shared catalogue for card artwork, screenshot galleries, personal ratings, quotes, and platform playtime. Roblox experiences have their own category and a three-column desktop showcase with fetched experience metadata. Game names in quotes link to the corresponding showcase.

Playtime is stored in minutes and formatted into hours and minutes for display. PC totals are loaded in the background from the playtime API; manual values remain the fallback when a game has no API data or the service is unavailable. Mobile and console totals remain independent of collector uploads.

The [Portfolio](https://paryx.uk/portfolio) is a space for Roblox work, with large featured projects followed by a compact project collection. No projects have been shared there yet.
